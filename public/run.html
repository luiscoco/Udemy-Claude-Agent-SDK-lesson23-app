01

Prepare the runtime

Use Node.js 24 or later. Windows may need Git Bash. This application needs a funded model API account, and the weather experiment needs access to Open-Meteo.

node --version
npm --version
02

Install and create your .env file

From presentations run these commands. Preserve an existing .env, enter your API key privately and keep credentials on the server.

cd .\agent-sdk\lesson23-advanced-tools
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Keep the server running. The friendly-error and chart CLI exercises call this app over local HTTP, so they also require it. No separate MCP service is started.

npm start
# http://127.0.0.1:3123
04

Measure read-only calls and inspect errors

Compare actual handler intervals. Then run the intentional HTTP 503 and uncaught exception. Tool error flags and the final query status are different evidence.

npm run sample:env -- parallel-readonly
npm run sample:env -- friendly-error
npm run sample:env -- uncaught-error
05

Inspect image and resource content

The image is bundled classroom sample data served over actual local HTTP. The report carries its content inline. Inspect native tool-result blocks as well as the formatted answer.

npm run sample:env -- image
npm run sample:env -- resource
06

Compare structured and mixed results

Structured mode pairs exact JSON with image and resource blocks, and tests a duplicate-text sentinel. Mixed mode keeps ordinary text alongside image and resource content.

npm run sample:env -- structured
npm run sample:env -- mixed
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3123
# Optional on Windows: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Keep the actual key private. No Managed Agents agent ID or environment ID is required. No duplicate snapshot is included.

Troubleshooting

Use the URL printed by startup. If another app occupies the port, change PORT and restart. If API credit is unavailable, add credit to the account used by this key. Weather HTTP or validation failures remain visible; no cached result replaces a failed live call. The error and chart CLI exercises require this web server to be running on the same PORT.
