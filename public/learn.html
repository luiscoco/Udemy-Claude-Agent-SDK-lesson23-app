01

Annotate truthfully

readOnlyHint allows read-only calls to run concurrently. The app measures actual handler intervals and reports overlap. An annotation does not enforce behavior or guarantee a particular schedule.

02

Return useful tool errors

A controlled local endpoint really returns HTTP 503. The handler returns isError: true with context. A second experiment throws a controlled exception so you can inspect the SDK-converted error result.

03

Keep tool and query outcomes separate

The SDK can deliver a tool error to Claude and still finish the query successfully. This is distinct from a model API, process or transport failure, which can still terminate a run.

04

Send images as actual bytes

The handler fetches a PNG from this app and returns raw base64 plus image/png. The chart is clearly labelled classroom sample data, not live weather. Inspect its image hash and the native image block.

05

Embed resource content

The report uses a classroom URI with inline Markdown text. The URI identifies the supplied content; the app does not read a file from that URI. Text, images and resources can appear together.

06

Return exact structured fields

The structured experiment returns a sample chart and its exact JSON points. Compare the native forwarded blocks: structured data, image and resource remain, while a duplicate text sentinel is omitted.
